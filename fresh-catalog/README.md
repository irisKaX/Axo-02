# AXO · Fresh Design Catalog

Nový samostatný katalogový základ s 12 sekcemi, uložený izolovaně v `fresh-catalog/` ve větvi `feat/fresh-design-catalog`.

## Sekce
1. Foundations
2. Tlačítka
3. Navigace
4. Inputy a formuláře
5. Karty
6. Dialogs a popovers
7. Feedback a status
8. Logo
9. Brand
10. Loaders
11. Další prvky
12. Dashboard

## Jak otevřít
Otevři soubor `fresh-catalog/index.html` přímo v prohlížeči nebo jej naservíruj jako statický web. Sekce se přepínají přes hash URL, funguje dark/light a mobilní navigace. V katalogu zatím nejsou hotové komponenty, pouze pracovní plochy.

## Bezpečné oddělení
Stávající `index.html`, existující Design System a dashboardové experimenty jsou beze změn. Tento commit nic nenasazuje. GitHub Pages pro novou větev není automaticky nakonfigurován.

Pokud má být katalog **v samostatném GitHub repozitáři**, založ nový prázdný repozitář a přenes do něj obsah `fresh-catalog/`; tento connector nemá oprávnění vytvářet repozitáře.
