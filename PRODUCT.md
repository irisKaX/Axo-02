# AXO-02 · kontext pro designové nástroje

Jde výhradně o existující Design System katalog HTML/CSS/vanilla JavaScript pro návrh a kontrolu komponent. Není to hotová aplikace, Dashboard ani aplikační prototyp. Existující Composition Lab a Widget Studio jsou součásti katalogu.

Kanonický projektový a designový kontext: [docs/SOURCE-OF-TRUTH.md](docs/SOURCE-OF-TRUTH.md). Před rozhodnutím čti tento soubor a skutečnou dotčenou komponentu. Tento stručný adaptér nepřidává produktové požadavky ani neschvaluje redesign.

Pracovní postup: [Design Guardian](.agents/skills/axo-design-guardian/SKILL.md) a [návod](docs/DESIGN-WORKFLOW.md). V tomto setupu pouze samostatná větev, bez UI změn a bez deploymentu.
